# Mohit Singh Mahra - Personal Portfolio Website

A modern, interactive, and responsive portfolio website built for **Mohit Singh Mahra**—Video Editor, Cinematographer, and Content Creator. 

The portfolio showcases featured video projects, work history, interactive 3D elements, dark/light theme switching, and an integrated contact form.

---

## ✨ Features

* **3D Interactive Hero:** Integrated with Spline 3D viewer for a dynamic hero section.
* **Dark / Light Theme Toggle:** Allows visitors to switch between dark and light modes seamlessly with state saved in `localStorage`.
* **Featured Projects Carousel:** Horizontal scrollable video project showcase with Google Drive modal video preview and Instagram dynamic link.
* **Responsive Navigation:** Mobile-friendly drawer navigation for smaller screen sizes.
* **Contact Form Integration:** Direct message delivery powered by Formspree.
* **Modern Design System:** Glassmorphism headers, smooth scrolling, neon hover accents, and dynamic gradient highlights.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structural layout.
* **CSS3:** Custom CSS variables for theme switching, Flexbox, CSS Grid, animations, and responsive media queries.
* **JavaScript (ES6):** Modal popups, smooth scrolling, local storage theme handling, and interactive elements.
* **Spline 3D:** Interactive WebGL 3D robot scene embed.
* **Formspree:** Backend-free contact form submission endpoint.
